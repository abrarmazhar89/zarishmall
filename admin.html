Tips for image URLs

• Google Drive: Share the file → Copy link → Change open?id= to uc?id=
• Imgur: Right-click image → Copy image address (ends in .jpg/.png)
• Cloudinary/any host: Any direct .jpg/.png/.webp link works
• URLs that show a red border failed to load — check the link

If you upload images directly to your GitHub repo, just set how many images are in the folder. Images must be named 1.jpg, 2.jpg, etc. inside a folder named after the handle.

How many images are in the folder

Expected file paths:

{handle}/1.jpg
images/{handle}/2.jpg

Upload your images to GitHub at handle/1.jpg, images/handle/2.jpg etc., then set the number above to match. The site auto-detects jpg, jpeg, webp, and png formats.

GitHub Sync Setup

How to get your GitHub Token (one-time setup):

1

Go to github.com/settings/tokens/new

2

Give it a name like zarish-mall-admin, set expiry to No expiration

3

Under Scopes, tick only repo (full control of private repositories)

4

Click Generate token and copy it. Paste it below.

Stored only in your browser. Never sent anywhere except GitHub's API.
